# KUKI GYMRATS ウエイトトレーニング管理システム
# 要求定義書

- 対象：KUKI GYMRATS（選手41名体制チーム）
- 作成日：2026-09-10

---

## 1. プロジェクトの目的・背景

KUKI GYMRATSの選手41名が行う週1〜2回のウエイトトレーニングのデータをデジタル化・可視化し、選手の成長を最大化する。
併せてペーパーレス化によるコーチ・トレーナーの管理負担軽減、コンディション管理（痛み・補食）を通じた怪我の予防と個別最適化（リハビリ選手・希望選択型メニュー対応）を実現し、チームの「日本一」達成を支援する。

---

## 2. ステークホルダー

| 役割 | 人数 | 主な利用シーン |
|---|---|---|
| 選手 | 41名 | スマートフォンから日々のコンディション・トレーニング記録を入力 |
| コーチ | 1名 | PCからメニュー配信・全選手状況の管理 |
| トレーナー | 1名 | PCから痛み・リハビリ・コンディション管理 |

---

## 3. ビジネス要求

### 3.1 選手側の要求
- スマートフォンから簡単にトレーニング実績（セット・重量・回数）を記録したい
- 目標重量（1RM比）が自動で表示されることで、毎回の計算を省きたい
- 自身の成長（1RM推移）をグラフで可視化して、モチベーションを高めたい
- 痛み・違和感を簡単に報告し、コーチ・トレーナーに伝えたい
- 補食の実施状況をチェックリスト感覚で管理したい
- チームメンバーの振り返りを読んで刺激を受けたい
- 希望するトレーニングメニューをリクエストしたい

### 3.2 スタッフ（コーチ・トレーナー）側の要求
- PCから全選手の状況を一元的に把握したい
- セットごとに強度（%1RM）・回数を細かく指定したメニューを配信したい
- 選手の痛み・コンディション状況をリアルタイムに把握して怪我を予防したい
- リハビリ中の選手のフェーズ管理とデータ確認をしたい
- 選手の成長グラフを見て個別指導に活かしたい
- 選手からの振り返りにコメントでフィードバックしたい
- 選手の新規登録・編集・退部処理を管理者として実施したい

---

## 4. 主要機能要求（概要）

### 選手用アプリ（モバイルファースト）
1. **ログイン**：名前選択のみ（パスワード不要）
2. **コンディション記録**：補食チェック・痛み部位・レベル入力
3. **トレーニング記録**：本日のメニュー表示、セット別重量・回数入力
4. **成長グラフ**：種目別1RM推移の可視化
5. **振り返り**：1日単位の自由記述、チーム閲覧、コメント機能
6. **メニュー希望**：希望プログラムのリクエスト申請

### スタッフ用ダッシュボード（PC最適化）
1. **概要サマリー**：全体状況の一覧確認
2. **痛み・コンディション監視**：選手の痛み報告状況
3. **メニュー配信**：セット別強度・回数指定での配信
4. **オプトイン承認**：希望メニュー申請の承認・却下
5. **リハビリ管理**：フェーズ管理・痛み履歴確認
6. **振り返り一覧**：全選手の振り返りへのコメント
7. **選手管理**：新規登録・編集・退部（管理者限定）

---

## 5. 非機能要求（概要）

- **デバイス対応**：選手用はスマホ最適化、スタッフ用はPC最適化
- **デザイン**：ダーク系背景（ブラック・ダークグレー）＋レッドアクセント
- **セキュリティ**：デモ用の簡易認証（名前選択のみ）。スタッフ機能は役割によるアクセス制御
- **データ保存**：Genspark Table APIによるサーバーサイド永続化
- **ホスティング**：Genspark Hosted Deploy（Cloudflare Workers）

---

## 6. 制約・前提条件

- 動画アップロード・閲覧機能は対象外（シンプル・軽量構成）
- 本番認証（パスワード・SSO等）は対象外（デモ用簡易ログイン）
- Supabase / Vercel / Next.js は使用しない
- 環境変数による設定は不要（Table APIはGenspark環境で自動設定）
